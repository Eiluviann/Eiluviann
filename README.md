### Hi, I'm Aurelio 👋

TypeScript developer based in València, Spain. I build developer tooling, much of it AI-assisted, and I specialise in ServiceNow Service Portal.

#### What I build

- **[vantage-cr](https://github.com/Vantage-CR/vantage-cr)**: AI-assisted interactive code review. The human reviews and the AI takes care of the navigation. Built with TypeScript, Tauri, tree-sitter and CodeMirror.
- **[sn-ajax-adapter](https://github.com/Eiluviann/sn-ajax-adapter)**: type-safe GlideAjax for ServiceNow without the boilerplate. Write a typed method on the server and call it like a promise on the client.
- **[servicenow-query-skill](https://github.com/Eiluviann/servicenow-query-skill)**: a security-first Claude Code skill that queries any ServiceNow table in plain English. It is read-only and runs locally.
- **[path-scout](https://github.com/Eiluviann/path-scout)**: the shortest path between you and your tools. A TypeScript monorepo with a plugin system.
